Where this jar came from
------------------------
There is no published 2.6.0 / Minecraft 26.3 build of Danse: the newest release on
Modrinth is 2.5.4+26.1, and CurseForge has no 26.3 file either. This jar was therefore
built from source, exactly as the upstream repository stands at

    commit 8af91e513e0216be491fb858aa130ded68213991   ("v2.6.0+26.3")

with

    git clone https://github.com/tomalbrc/danse.git
    git checkout 8af91e513e0216be491fb858aa130ded68213991
    ./gradlew build          # with JAVA_HOME on a JDK 25 — the build sets release 25
                             # but declares no toolchain, so it fails on an older default JVM

It is used by ovvar for development and tests only (modCompileOnly + modLocalRuntime); it
is never shipped, and ovvar never declares Danse in its `depends`. The jar bundles Danse's
own included libraries (blockbench-import-library, DialogUtils, sgui, placeholder-api and
map-canvas-api) as nested jars, which is how upstream publishes it.

Replace this file with the official artifact as soon as tomalbrc releases 2.6.0 for 26.3.

danse — player gestures for Fabric servers, by tomalbrc, Drex and ExtraJuiceMan.
  Upstream: https://github.com/tomalbrc/danse
  Licence: GNU Affero General Public License v3.0 (LICENSE_danse inside the jar). Upstream's
  fabric.mod.json says LGPL-3.0-and-later while its LICENSE file is AGPL-3.0; we follow the AGPL.

This jar is built from Metacraft's fork, which is public:
  https://github.com/Froosty11/danse   branch metacraft   commit 5e424de6c12c0a708725bd06f6a7e29f0cb98437
with
  git clone https://github.com/Froosty11/danse && cd danse && git checkout 5e424de6c12c0a708725bd06f6a7e29f0cb98437
  JAVA_HOME=<a JDK 25> ./gradlew build

Changes from upstream v2.6.0+26.3: mixins listed as common, a body-layer API
(de.tomalbrc.danse.api, with cropped-texture shells), and /danse source (open to every player,
also /gesture source), which tells players where this source is.

It is its own jar: nothing in METAmods includes or relicenses it. Ovvar only calls its API.

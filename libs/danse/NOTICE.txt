This jar is built from Metacraft's fork, which is public:
  https://github.com/Froosty11/danse   branch metacraft   commit 86ae3622e550ff8d0ac0eeb5fe3b02c22561d31b
with
  git clone https://github.com/Froosty11/danse && cd danse && git checkout 86ae3622e550ff8d0ac0eeb5fe3b02c22561d31b
  JAVA_HOME=<a JDK 25> ./gradlew build

Changes from upstream v2.6.0+26.3: mixins listed as common, a body-layer API
(de.tomalbrc.danse.api) and /gesture source, which tells players where this source is.

It is its own jar: nothing in METAmods includes or relicenses it. Ovvar only calls its API.
